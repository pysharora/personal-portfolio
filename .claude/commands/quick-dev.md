# Quick Dev

Read a spec path from `$ARGUMENTS` or use it as the description. Inspect the nearest pattern, state a short plan, and make the smallest complete change. If scope expands to a new layer, five or more files, three or more independent components, or sensitive data/integration work, pause and recommend `/ralph` or `/bmad-run`.

Run `/check` plus relevant visual, responsive, theme, motion, accessibility, content, and SEO checks. Report files, acceptance evidence, and limitations without claiming nonexistent tests.
