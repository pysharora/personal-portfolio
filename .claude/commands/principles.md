# Principles

Read project docs, source conventions, CI, release workflow, and existing artifacts. Run a concise Product Owner versus Tech Lead debate over portfolio value, factual integrity, code quality, architecture, accessibility/UX, themes, SEO, verification, security/privacy, performance, and delivery. Ask the user to arbitrate genuine conflicts. After confirmation, write `.claude/output/principles.md` with rationale, measurable expectations, and exceptions.
