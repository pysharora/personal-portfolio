# BMAD Deliver

Read architecture, backlog, act report, principles, and final diff. Run `/release-check`; verify content facts, metadata/JSON-LD, robots/sitemap, assets/CV, all themes, responsive layouts, accessibility, CI, configuration docs, and deployment/rollback notes. Perform proportional security/dependency review.

Write `.claude/output/release-notes.md` with user-visible changes, decisions, evidence, limitations, configuration, and deployment/rollback guidance. Present a readiness verdict. Commit, push, merge, tag, deploy, and publish require explicit authorization.
