# Party

Select two to four relevant installed roles, normally product-owner, architect, tech-lead, and design-reviewer. Announce the panel; run two concise rounds with a rotating devil's advocate and user checkpoints; summarize consensus, dissent, risks, and recommendation. After confirmation, save `.claude/output/party-{slug}.md`. Ground arguments in repository evidence and portfolio goals.
