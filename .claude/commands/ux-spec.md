# UX Spec

Read the problem, principles, docs index, current route/component flow, and visual rules. Define audience journeys, entry points, success/recovery paths, page purpose and hierarchy, content states, navigation, interaction feedback, component reuse, responsive behavior, all four theme modes, keyboard/focus behavior, semantics, contrast, reduced motion, and asset/alt-text needs.

Preserve the warm-neutral editorial direction and avoid generic SaaS UI. Present key flows and decisions for confirmation, then write `.claude/output/ux-spec.md`.
