# BMAD Break

Read the brief, AGENTS, docs index, source, and existing principles/problem artifacts. Identify target audiences, user value, current behavior, desired outcomes, personal facts that require confirmation, constraints, integrations, non-functional needs, and exclusions. Ask at most five high-impact questions per round.

Propose stories with `id`, actor, `i_want`, `so_that`, priority, Given/When/Then scenarios, and verification. Present scope and assumptions before saving. After confirmation, write `.claude/output/problem.yaml` with the problem, audiences, features/stories, constraints, integrations, non-functional requirements, out-of-scope items, and assumptions. Never invent biography, employment, metrics, testimonials, contact details, or availability.
