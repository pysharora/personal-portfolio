# GSD Prep

Require approved architecture and backlog. Map only relevant routes, components, typed data, styles, theme layers, assets, metadata, scripts, CI, and conventions. Classify tasks as existing, partial, new, or obsolete; split oversized work; group dependency-safe rounds; assign exclusive file ownership; and identify shared contracts.

Write `.claude/output/gsd/gap-analysis.md`, focused maps, one pack per task under `gsd/context-packs/round-N/`, and `gsd/prep-report.md`. Each pack contains WHY, acceptance criteria, relevant architecture, exact existing patterns, contracts, owned files, dependencies, and verification. Ask for confirmation.
